# Compliance mapping aid

This document is a planning checklist, not a certification or legal opinion.

| Area | Relevant controls |
|---|---|
| SOC 2 CC6 | API authentication, least privilege, revocation, secure secrets |
| SOC 2 CC7 | Health checks, structured security events, verification and alerting |
| SOC 2 CC8 | Versioned hash format, migration records, change review |
| ISO 27001 Annex A | Access control, cryptography, logging, backup and incident response |
| GDPR | Data minimization, retention, deletion workflow, access logging, DPA review |

Production evidence still requires independent testing, policies, ownership,
records of processing, and organization-specific risk assessment.
